# 우리집 가계부

부부 공동 사용 가계부 웹앱 (React + Vite + TypeScript, 원 단위).

## 계산 규칙
- **카드 주기**: 매월 14일 ~ 다음 달 13일. 14일이 되면 새 주기로 자동 전환되어 카드 사용액이 0원부터 다시 집계됩니다. (◀ ▶ 로 지난 주기 조회)
- **월급**: 매월 21일. 주기 종료 달의 월급이 해당 카드 주기의 결제 재원입니다. (예: 10/14~11/13 주기 ↔ 11/21 월급)
- **카드로 쓸 수 있는 총액** = 월급 + 기타수입 − 계좌이체/현금 고정비 − 현금·이체 지출 − 저축목표
- **남은 카드 한도** = 위 총액 − (카드 고정비 + 카드 변동 지출)
- 하루 사용 가능액 = 남은 한도 ÷ 주기 종료까지 남은 일수

## 개발
```bash
npm install
npm run dev     # 로컬 실행
npm test        # 계산 로직 테스트
npm run build   # dist/ 빌드
```

## 배포
`main` 브랜치에 push하면 GitHub Actions가 빌드해서 GitHub Pages에 배포합니다.
(저장소 Settings → Pages → Source: **GitHub Actions**)

## 부부 공유 (Firebase Firestore)
앱의 **설정 → 부부 공유**에서 `firebaseConfig`와 가족 코드를 입력하면 실시간 동기화됩니다.
설정값은 저장소가 아닌 각자 기기의 브라우저에만 저장됩니다.
Firestore 규칙은 앱 설정 화면에 안내되어 있습니다.
